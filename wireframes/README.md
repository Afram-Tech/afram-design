# Wireframes

Low-fidelity layouts for flows that aren't built yet. Wireframes describe **structure and
content**; visuals come from `principles/` and the component kit.

Accepted formats:

- Markdown with an ASCII layout and a component list (preferred: agents read it directly).
  Copy [_template.md](_template.md).
- PNG or SVG exported from Figma, with a `.md` next to it that names the components and states.
- A link to the Figma frame (the agent reads it through the Figma MCP).

Name them `<area>-<screen>.md`, for example `financier-request-review.md`.

Wireframes for a single ticket go on the Linear ticket, not here. Put a wireframe here when it
describes a pattern several tickets will reuse.
